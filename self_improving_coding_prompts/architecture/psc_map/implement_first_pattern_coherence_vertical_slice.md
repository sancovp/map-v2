# Implement the First Pattern-Coherence Vertical Slice

PromptType: WorkPrompt

SituationClass: Domain-neutral proof-shell hardening with a consumer-owned executable fixture.

ConcreteContext: MAP currently lets one typed construction adapter authorize both `candidate_*` and `source_*`. Implement the first `categorical_ring` proof slice while preventing candidate authors from supplying their own evidence.

AgentOrientation: Make the smallest behaviorally complete change. MAP owns only generic adapter authority and certificate plumbing; the test fixture owns ring semantics and PSC models.

HardQuestions:

- Can any construction adapter emit `source_*` after this change?
- Can any observation adapter emit `candidate_*` or derived proof terms?
- Does MAP bind observation schema, payload, lowering, and facts into proof state?
- Do complete and partial coverage produce different outcomes for absence?
- Are contradiction and ordinary unresolved residue observably distinct?

MeasurableOutcome: Separate construction and observation adapter protocols exist; lattice nodes can attach trusted observations; stale observation adapters reopen proof; a consumer-owned categorical-ring fixture proves clean ONT and exact SOUP residue for direct leak, partial coverage, and ambiguous role binding; the focused suite passes.

ReplayInstructions:

1. Narrow `ConstructionAdapter` to `candidate_*` only.
2. Add a parallel `ObservationAdapter` restricted to `source_*` only.
3. Persist observation identity separately and include it in packet/certificate fields.
4. Add an explicit lattice operation to attach observations after candidate construction.
5. Keep ring PSC models and Prolog theory under test fixtures.
6. Implement exact categorical-ring obligations and residue.
7. Test forgery, staleness, coverage, ambiguity, contradiction, and ONT.
8. Run the focused standalone suite.

ShapeInvariant: Candidate authors can propose what code means; only a pinned observer can state what the code contains; only the domain theory can derive proof status.

AllowedVariation: Names of fixture classes and facts may vary while fixed authority and proof semantics remain.

ForbiddenDrift: No code-domain imports in `map_v2`; no source facts through construction; no candidate facts through observation; no false clean result from partial coverage; no prose-only proof.

VerificationGate: All focused tests pass and explicit adversarial tests demonstrate that each authority boundary rejects forged predicates.

PersistenceTarget: MAP generic adapter/lattice code plus consumer-owned tests and fixtures.

PromotionSignal: Extract the fixture into a standalone pattern-coherence consumer after the vertical slice is green and its package boundary is proven.
